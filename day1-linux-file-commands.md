# Day 1 - Linux File & Directory Commands

## Commands Practiced

### pwd
Shows current working directory.

Example:
pwd

---

### ls
Lists files and folders.

Example:
ls
ls -l
ls -a

---

### cd
Used to change directory.

Example:
cd projects
cd ..

---

### cp
Used to copy files.

Example:
cp linux.txt projects/

---

### mv
Used to rename or move files.

Example:
mv notes.txt devops-notes.txt

---

### tree
Shows folder structure.

Example:
tree
tree /F
