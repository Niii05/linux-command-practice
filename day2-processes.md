# Day 2 - Linux Processes

## Commands Learned

ps → shows processes in current terminal

ps aux → shows all processes in system

ps aux | grep bash → finds specific process

top → live system monitoring

htop → better interactive monitoring

kill → stops a process

---

## Key Concepts

- Process = running program
- Each process has a PID (Process ID)
- grep is used to filter output

---

## Observations

- ps shows limited processes
- ps aux shows full system processes
- grep also appears as a process
- htop is easier to use than top
